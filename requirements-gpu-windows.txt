# Optional GPU acceleration for Whisper STT on Windows — NOT installed by CI.
#
# Why a separate file, not requirements-lock.txt: CI installs the lockfile on
# every Windows run, and these two wheels are ~553 MB (cublas) + ~732 MB
# (cudnn) ≈ 1.3 GB — they must never inflate every CI run. STT already works
# CPU-only from the base requirements; this file is a manual opt-in for the
# owner's RTX 4070 machine.
#
# ctranslate2 (pulled in by faster-whisper) needs cuBLAS (CUDA 12) + cuDNN 9
# at model-load time. The NVIDIA driver alone is not enough:
# ctranslate2.get_cuda_device_count() succeeds on the driver, but the actual
# model load throws a cublas/cudnn RuntimeError without these, and
# jarvis/voice/stt_whisper.py then falls back to CPU ("CUDA libraries
# unavailable"). jarvis/voice/stt_whisper.py::_register_cuda_dll_dirs()
# prepends these packages' site-packages/nvidia/*/bin dirs to PATH before
# importing faster_whisper, so no code change is needed once they're installed.
#
# Install (from the repo root, into the project venv):
#   .\.venv\Scripts\python.exe -m pip install -r requirements-gpu-windows.txt
#
# Verify (forces CUDA so a real failure can't hide behind silent CPU fallback):
#   $env:WHISPER_DEVICE="cuda"; .\.venv\Scripts\python.exe -m jarvis --voice
#   -> the "CUDA libraries unavailable — falling back to CPU" line must be ABSENT.
#
# Versions below are the EXACT set smoke-tested green on 2026-07-24 (RTX 4070,
# driver 610.74, ctranslate2 4.8.1, faster-whisper 1.2.1): real model load +
# transcription on device 'cuda', RTF ~0.13 vs 10-20 s on CPU. cuDNN must stay
# on the 9.x line (ctranslate2 4.5+ dropped cuDNN 8). Bump deliberately + re-run
# the forced-CUDA smoke test before changing any pin.
nvidia-cublas-cu12==12.9.2.10
nvidia-cudnn-cu12==9.25.0.15
nvidia-cuda-nvrtc-cu12==12.9.86
